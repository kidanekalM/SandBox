# Circular Side Menu Template

Standalone HTML, CSS, and JavaScript prototype for a circular menu:

- starts centered on the page
- distributes menu items around the circle
- docks partly into the left side after selection
- keeps only a visible slice of the circle on screen
- rotates clockwise in equal 72-degree steps at a constant speed
- keeps labels upright while the orbit rotates
- supports mouse, touch, and keyboard selection
- adapts the orbit and detail panel for mobile screens

## Files

- `index.html`
- `styles.css`
- `app.js`
